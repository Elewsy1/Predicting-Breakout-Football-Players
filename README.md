# Predicting Breakout Football Players

IDSC-GH 5010, Fall 2026 · Shiyan Wang, Junius, Noah Feng, Xianghe Meng

Can FIFA ratings and match records tell a scout which players will improve the most next year?
The project is split into one folder per deadline. Each folder is complete and runs on its own,
so it can be handed in as it is.

| Folder | Deadline | Contents |
|---|---|---|
| [`A_checkin_1124/`](A_checkin_1124/README.md) | 24 Nov check-in | cleaning, exploration, first features, baseline |
| [`B_checkin_1201/`](B_checkin_1201/README.md) | 1 Dec check-in | everything in A + model selection, final test, explanations, draft report, slides plan |
| [`C_final_1208/`](C_final_1208/README.md) | final submission | the final code, results and report |

For the team: `data_raw/database.sqlite.zip` is the Kaggle database. Inside this repository the
notebooks unzip it automatically the first time, into `_local/` (not tracked by git). Outside the
repository, put `database.sqlite` in the folder's `data/` directory as its README says.
